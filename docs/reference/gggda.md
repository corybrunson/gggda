# **gggda** package

This is a **[ggplot2](https://ggplot2.tidyverse.org/)** extension for
multivariate and geometric data analysis.

## Acknowledgments

This package was spun off from
**[ordr](https://cran.r-project.org/package=ordr)**. Many users have
identified problems and suggested improvements.

Development benefitted from the use of equipment and the support of
colleagues at [UConn Health](https://health.uconn.edu/) and at [UF
Health](https://ufhealth.org/).
